# Dons
# Адаптивный веб-сайт для автосервиса «ДОНС»

Коммерческий Landing Page для локального бизнеса с полной мобильной адаптивностью и интерактивными элементами.

## Стек технологий
* **HTML5** (Семантическая и валидная верстка)
* **CSS3** (Flexbox, Grid Layout, Адаптивность через Media Queries)
* **Vanilla JavaScript** (Интерактивные компоненты, клиентская валидация формы)

## Ключевые особенности
* **Mobile-First адаптивность:** Сайт плавно подстраивается под экраны смартфонов, планшетов и десктопов.
* **Pixel Perfect:** Качественная верстка с точным соблюдением отступов и UI-элементов.
* **Интерактив на JS:** Кастомные элементы интерфейса и базовая проверка полей перед отправкой.
* *(В разработке)* Интеграция формы с бэкендом для автоматического сбора заявок.
